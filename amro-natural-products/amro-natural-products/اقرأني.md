# موقع عمرو أبو محمد للمنتجات الطبيعية

## محتويات المشروع
```
index.html          → الموقع الرئيسي
2009admin.html       → لوحة تحكم الأدمن (إضافة/حذف المنتجات)
assets/css/          → التنسيقات
assets/js/           → أكواد الموقع ولوحة التحكم + إعدادات فايربيز
assets/images/amro.jpg → صورتك المستخدمة في الموقع
firebase.json         → إعداد الاستضافة على Firebase (يخلي رابط /2009admin يشتغل بدون .html)
_redirects             → نفس الفكرة لو استضفت الموقع على Netlify
firestore.rules        → قواعد حماية قاعدة البيانات
```

## 1) الدخول للوحة التحكم
مفيش أي حساب أو إيميل مطلوب. افتح `/2009admin` واكتب كلمة السر:

```
1282009
```

وهتدخل على طول للداشبورد. لو عايز تغيّر كلمة السر لاحقًا، هتلاقيها في أول ملف `assets/js/admin.js`:
```js
const ADMIN_PASSWORD = "1282009";
```

## 2) تفعيل قاعدة البيانات (Firestore) — خطوة أساسية
1. من [Firebase Console](https://console.firebase.google.com) → مشروع **amro-2b1d2** → **Firestore Database** → لو أول مرة تعمل **Create database** (اختار أي وضع)
2. روح لتبويب **Rules** والصق فيه محتوى ملف `firestore.rules` ودوس **Publish**

من غير الخطوة دي الموقع مش هيقدر يقرأ أو يكتب منتجات خالص.

**ملاحظة أمان بسيطة:** بما إن الدخول بقى بكلمة سر واحدة بس من غير حساب حقيقي، فأي حد يعرف كلمة السر (أو يفتح كود الموقع بعناية) يقدر يضيف/يحذف منتجات. الرابط السري + كلمة السر كافيين لموقع بسيط زي ده، بس لو حبيت حماية أقوى في المستقبل (حساب حقيقي بإيميل) قولّي وأظبطهولك.

## 3) تفعيل رفع الصور (ImgBB — مجاني تمامًا وبدون بطاقة ائتمان)
فيرباس بقى بيطلب ترقية مدفوعة (Blaze) عشان تستخدم خدمة تخزين الصور بتاعته، فاستبدلناها بخدمة **ImgBB** المجانية بالكامل لاستضافة صور المنتجات:

1. روح على [api.imgbb.com](https://api.imgbb.com/) ودوس **Get API Key**
2. سجّل حساب مجاني بإيميلك (من غير أي بطاقة بنكية)
3. هيديك مفتاح API (سطر طويل من الحروف والأرقام) — انسخه
4. افتح ملف `assets/js/admin.js` ولاقي أول سطرين:
   ```js
   const IMGBB_API_KEY = "ضع_مفتاح_ImgBB_هنا";
   ```
   واستبدل النص بين علامتي التنصيص بالمفتاح اللي نسخته
5. احفظ الملف وارفعه تاني لو الموقع أصلاً منشور

بعد الخطوة دي، أي صورة ترفعها من لوحة التحكم هتترفع لـ ImgBB تلقائيًا ويتحفظ رابطها مع المنتج في Firestore.

## 3) رفع الموقع (الاستضافة)
أسهل طريقة لأنك أصلاً عندك مشروع Firebase جاهز:

```bash
npm install -g firebase-tools
firebase login
cd اسم-المجلد
firebase init hosting   # اختار "Use an existing project" → amro-2b1d2
firebase deploy
```

هيديك رابط زي: `https://amro-2b1d2.web.app`

بديل: تقدر ترفع نفس الملفات على Netlify أو أي استضافة استاتيك تانية — ملف `_redirects` موجود يخلي `/2009admin` يشتغل هناك برضو.

## 4) استخدام لوحة التحكم
- افتح `https://رابط-موقعك/2009admin`
- اكتب كلمة السر `1282009`
- اكتب اسم المنتج، السعر، وارفع صورة من موبايلك
- دوس "إضافة المنتج" — هيظهر فورًا في الموقع الرئيسي بدون ما تحتاج تعمل حاجة تانية
- تقدر تحذف أي منتج من نفس اللوحة

## 5) رقم الواتساب وصفحة الفيسبوك
لو حبيت تغيّرهم في المستقبل، هتلاقيهم في أول ملف:
`assets/js/firebase-config.js` → داخل `CONTACT`

```js
export const CONTACT = {
  whatsappNumber: "201024002498",
  facebookUrl: "https://www.facebook.com/share/1E9X8r4DH1/"
};
```

كل زرار واتساب في الموقع (زرار الطلب في كل منتج + الزرار العائم + قسم التواصل) بيتولّد تلقائي من الملف ده، فمحتاج تغيّره في مكان واحد بس.

## ملاحظة أمان مهمة
مفتاح الـ `apiKey` بتاع فايربيز اللي في `firebase-config.js` طبيعي إنه يكون ظاهر في كود أي موقع فايربيز (مش سر) — الحماية الحقيقية بتيجي من الـ Rules (خطوة 2) وتسجيل الدخول (خطوة 1)، وده بالظبط اللي عملناه.
